Add Presence to {{ROOM}}

Paste this one script tag into your site's HTML. It shows how many people are on the page right now, streams everyone's live cursor, and lets visitors type floating messages to each other — all scoped privately to the {{ROOM}} room.

1. Add this before </body>

<script src="{{ORIGIN}}/widget.js" data-room="{{ROOM_ATTR}}" async></script>

2. That's it

  • No account, no API key, no server-side setup.
  • Anyone loading a page with this snippet joins the {{ROOM}} room automatically.
  • Cursors and typing never interrupt your site's own forms or inputs.
  • Want a separate space? Use a different room name, e.g. {{ORIGIN}}/{{ROOM}}-staging.
