Presence
Free · No login required

Add Presence to {{ROOM}}

Paste this one script tag into your site's HTML. It shows how many people are on the page right now, streams everyone's live cursor, and lets visitors type floating messages to each other — all scoped privately to the {{ROOM}} room.

1. Add this before </body>

<script src="{{ORIGIN}}/widget.js" data-room="{{ROOM_ATTR}}" async></script>

2. That's it

  • No account, no API key, no server-side setup.
  • Anyone loading a page with this snippet joins the {{ROOM}} room automatically.
  • Cursors and typing never interrupt your site's own forms or inputs.
  • Want a separate space? Use a different room name, e.g. {{ORIGIN}}/{{ROOM}}-staging.

3. Advanced options (optional)

AttributeWhat it does
data-room Which room to join. Anyone using the same room name (on any site) shares presence. Required — already set to {{ROOM}} above.
data-badge="false" Hides the small "N people here" pill in the bottom-right corner. Use this if you're building your own count display with the presence:update event below.
data-cursors="false" Turns off live cursors entirely — no dot for you, none for anyone else, and your mouse position is never sent. Visitor count and typed messages still work.
data-messages="false" Turns off typed message bubbles entirely — typing on the page is never captured or sent, and no one's messages are shown. Visitor count and cursors still work.
data-uid="…" Overrides the visitor identity. By default the widget stores a stable id in sessionStorage — the same browser tab keeps its identity across reloads, but a new tab (or a new visitor) is always counted separately. Set this only if your page needs to control that identity itself (for example, to intentionally give someone a fresh identity on every reload).

4. Build your own UI (optional)

The widget dispatches a presence:update event on window every time the visitor count or your queue position changes (event.detail.count, event.detail.room, event.detail.you), so you can render your own count/badge instead of the built-in one — for example, to show a live number of connections: 
window.addEventListener("presence:update", (event) => {
  const el = document.getElementById("presence-count");
  if (!el || typeof event.detail.count !== "number") return;
  el.textContent = `${event.detail.count} online`;
});
